# Pune Expense Manager
Offline Android expense tracker with ₹10,000 monthly budget, seven categories, add expense, monthly spend/remaining, 90% warning, expense history and delete. Data stays locally on the phone.

The project sets both Java and Kotlin JVM targets to 17. Upload the contents of this folder to the root of your GitHub repository (not the ZIP file). The included Actions workflow builds `app/build/outputs/apk/debug/app-debug.apk`. In GitHub open Actions, select Build Android APK, then download the `PuneExpenseManager-APK` artifact from a successful run.
